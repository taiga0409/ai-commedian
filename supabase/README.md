# supabase ディレクトリについて

このディレクトリには、Supabase で管理しているデータベースのテーブル、権限、初期データなどを作成・確認したときに使用した SQL を置いています。

これらの SQL ファイルは、Supabase 側のデータ管理作業の記録用です。ローカル環境でアプリを起動・開発するときには一切使用していません。また、アプリケーションの実行時にもこのディレクトリ内のファイルは参照されません。

ファイルを変更したり Supabase 上で実行したりする場合は、データベース構造やアクセス権限、登録済みデータに影響する可能性があります。内容と影響範囲を確認したうえで扱ってください。
